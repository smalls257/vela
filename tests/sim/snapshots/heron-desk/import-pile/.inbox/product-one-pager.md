# Heron: product one-pager

From the product owner, 2026-10-05.

Heron reads Teams, Zoom, Outlook and documents, and writes a 7:30 digest each morning and a prep note ten minutes
before each meeting. The agent on the laptop collects, and a cloud service writes the summaries with a hosted
language model, because the on-device model is poor and the digest should follow the person across devices. A
team dashboard shows adoption by team. Pilot starts 2 February 2027 with Client Delivery.
