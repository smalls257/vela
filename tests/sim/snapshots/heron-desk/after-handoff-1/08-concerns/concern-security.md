# Security

Who can call what, and what data each boundary carries.

## Strategy

In the first release no text leaves the device, the line the solution lead holds for the security pack and the CISO's position requires. Whether reading calendar entries from Microsoft counts as text leaving the device is the CISO's call and gates the rest. Whether Heron needs an app registration or only each person's sign-in is also open.
