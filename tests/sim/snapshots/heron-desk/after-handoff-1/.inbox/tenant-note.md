# Microsoft 365 tenant note

Prepared by the IT endpoint lead, 2026-10-02.

- One tenant, about 4,200 users. Devices: 3,100 Windows managed by Intune, 1,100 Macs managed by Jamf.
- Staff cannot install software. Everything is pushed from Intune or Jamf.
- Teams transcripts exist only where the organiser turned them on, in the organiser's OneDrive.
- A Graph app registration is raised through the identity team. Calendar and mail can be read with each user's own
  consent. Reading transcripts needs tenant admin approval.
- Frankfurt (about 600 staff) has a works council.
