# From the CIO: Heron

Written 2026-09-30, to the leadership team.

A desk helper for every Mac and Windows PC. Staff install it themselves in two minutes and it quietly watches
their meetings, email and documents. It runs on the PC, so the data never leaves the machine and there is
nothing for privacy or the works councils to worry about. Staff choose to install it, so consent is covered. It
needs only each person's own Microsoft 365 sign-in. Pilot in January, firm-wide by the summer. Everyone is on
Windows, so we start there.
