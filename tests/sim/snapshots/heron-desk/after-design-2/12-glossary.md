# Glossary

One paragraph per term: the term in bold, then what it means in this initiative.

**Heron:** the working name for the desk helper the chief information officer asked for. It reads a person's meetings, mail and documents and writes them a morning digest.

**Digest:** the note Heron writes at 7:30 each morning to tell a person what matters that day.

**Prep note:** a short note the product owner's design writes ten minutes before each meeting.

**Intune and Jamf:** the tools IT uses to push software to laptops, Intune for Windows and Jamf for Mac. Staff cannot install anything themselves, so Heron has to be packaged for both.

**Text call:** the open decision on whether meeting, mail and document text may leave the laptop in the pilot.

**Impact assessment:** the assessment the data protection officer's view waits on. Nobody is yet recorded as starting it.

**On-device model:** a language model that runs on the person's own laptop, so the text it reads never leaves the device. The first release uses one to write the digest and the prep note.

**Receipt:** a record the Desktop agent could send to Consent and identity after each read, saying which source, how many items and when, with no text. The first release does not send receipts.

**Calendar-only note:** a digest or prep note written from a meeting's calendar entry alone, because no Teams transcript exists or Heron may not read it. The note says so, so the reader knows it is thin.

**Consent and identity:** the shared service that keeps a record of who agreed to what and who withdrew, and answers the Desktop agent's consent check. The works council can audit it.

**Summariser:** the service that writes the digest and the prep note from the calendar entries and attendees the Desktop agent sends it.
