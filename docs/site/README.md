# The example site

What `https://smalls257.github.io/vela/` serves, from the `gh-pages` branch:

- `index.html`: the home page (this folder).
- `tracer-bullets.html`: `docs/explainers/tracer-bullets.html`.
- `guide.html`: `docs/GUIDE.html`, generated by `python3 docs/render_doc.py docs/GUIDE.md`.
- `dashboard.html`: the Heron example, built with `planner explore <heron vault> --out dashboard.html`.

Publish by copying these into a `gh-pages` worktree, committing and pushing; the pre-push hook runs `tools/check_site.py` on that branch.
