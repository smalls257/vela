# Set up the plan (about 5 minutes)

You'll get answers about the plan in plain words, with the lists and diagrams beside them. Nothing you do changes the plan.

1. **Install the reader.** In Claude, open Customize, then Plugins, then Upload, and pick `vela-reader.zip` (it came with this page).
2. **Make a folder for it**, for example `Documents/Our plan`, and choose it as the working folder. It can't be a OneDrive or SharePoint folder.
3. **Open the plan.** Say *open the plan* and paste the GitHub link you were sent.
4. **Ask what you'd ask me.** *Are we on track for the date?* · *What's stuck?* · *What do you need from me?*
5. **Next week, say *get the newer plan*.** The next answer starts with what changed.

Want the whole picture? Say *show the dashboard*.

If the link doesn't work, Claude says why in a sentence. Ask me to send the plan as a file instead: put the file in the same folder and say *open it*.
