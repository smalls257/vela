# Handing an app over

Read when a Grill's item is an app's handoff. `SKILL.md` has already stopped a reader copy.

1. Run `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/planner ladder` and read the list under "Handoff" in `CONVENTIONS.md`. The epics are not on it: epics come after handoff, so neither the epics nor the epics gate holds a handoff back, and another app's gaps never do. Say once what is not met, as one list in plain words, and offer to hand over anyway; that is an override named `"handoff checklist"`, as `START.md` says. Do not ask about each line.
   Then run `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/planner next` and `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/planner check`, and take from them what the senior would accept without a yes: each item in the app's slice that is still draft or assumption (acceptance criteria included), each contract with no case table, and each provider the app calls that nobody has designed. Say these in the same plain list, before the read-back in step 3, so the lead hears them and the senior does.
2. The senior who takes the app is named, with a handle. They are present and say yes, or their answer is quoted with the channel and the date, or the user decides on their behalf, recorded as GATE-5 says. If nobody is named, ask the user first, as `MODES.md` says under "Unknowns"; if they cannot name one, write the unknown and end the session.
3. Read back what the senior takes, and beside each item whether it is firm (decided or fact) or not (draft, assumption, no case table): the app, its runtime page, the contracts it provides and consumes, its epics, and every open unknown that blocks any of them. Also read back the first thin path (the tracer, as `CONVENTIONS.md` defines it under "Releases"; say what it is the first time), and this app's piece of it: the steps of those flows this app is on. If the vault names none, offer the choice in plain words: pick the first path now, or hand the app over as it is. Also read back the links recorded for the app and each of its epics, and say which have none: "The team will look for the code, the wiki and the tracker items here. Anything to add before you hand over?" Record only what the user gives, and let them skip. Get an explicit yes.
4. On the app page, write `handed_off: "<senior>, <today>, PR pending"` and set `stage` to the stage `planner ladder` says the pages reach. If an open unknown asks who the senior is, resolve it with the name. Commit. Tell the senior that their tech design and build plan go in this vault, under `docs/`, when they run the skills from the vault root, and that the explorer then shows them with no setup. Do not run `planner handoff` here: close commits everything first, then writes the manifest, so it records a clean commit, and then the PR number.
